# 自主任务上手(3 分钟版)

> 自主任务 = 你给一个**目标**,编排器自己拆步骤、开子会话干活、判官逐轮验收,你只看结果。实现:`scripts/pipeline.mjs`(M11-P2b 编排器 + P2a 判官)。

## 〇、口令方式(推荐,0.0.16.21 起)

对任何已接入记忆系统的工作区里的 agent 直接说:

- **开自主任务 "目标" [阶段数 纠偏数]** —— agent 用分离进程启动,立即回你目标/日志/进度查询方式;目标**必须带引号**(防讨论误触)。会话可以关,任务继续跑,完成弹窗。
- **自主任务状态** —— 一段话汇报阶段进度与判官近况。
- **停自主任务** —— 结束任务。

下面的手动命令与口令等价,适合脚本化场景。

## 一、怎么开始(一条命令)

```bash
node scripts/pipeline.mjs <工作区目录> "<你的目标>" [maxStages=4] [perStageBudget=3]
```

例:

```bash
node scripts/pipeline.mjs H:/ai_works/ModelTrainPrj "整理 data/raw 下的语料并生成清洗报告.md"
```

- maxStages:最多拆几个阶段(默认 4);perStageBudget:每阶段最多纠偏几轮(默认 3)。
- 目标写**成品和验收标准**,别写步骤——拆步骤是编排器的活。

## 二、开始前检查(3 项)

1. **hub 在线**:`http://127.0.0.1:45678` 可访问(离线时每阶段少记忆预注入,不致命但降智)。
2. **工作区已登记**:目录下有 `.brain.json`(没有就先 `node <SimpleAIBrain>/scripts/enroll.mjs <工作区>`,登记会自动把凭证写进 .gitignore)。
3. **DSH 可用**:编排器通过 DSH 的 ACP 通道开子会话(模型路由固定 litellm-funplus/glm-5.3-flash)。

## 三、运行中会发生什么

- 目标 → LLM 生成阶段计划 → **逐阶段开独立子会话**(阶段间不共享对话,只靠文件交接)。
- 每阶段产物过**文件硬闸**(输出文件必须存在且 ≥20B,支持 glob:前缀*后缀),再交**判官**审:pass / fix(定向纠偏)/ escalate。
- 每阶段自动**预注入记忆**(编排器代查,budget 800)——所以登记过的工作区干得更好。
- 判官每轮决策追加到 `<工作区>/判官_日期.md`,全程可回看。
- 全部完成(或卡死)会**弹窗提醒**你。

## 四、文件都在哪

| 文件 | 作用 |
|---|---|
| `<工作区>/_pipeline/plan.json` | 阶段计划。**想人工接管拆步骤:提前放好这个文件**,编排器直接用(跳过 LLM 规划) |
| `<工作区>/_pipeline/state.json` | 运行状态(断点)。**中断了?原命令重跑即续**,已完成阶段不重复 |
| `<工作区>/判官_日期.md` | 判官决策留痕(问题→决策) |

## 五、结束后

对 agent 说一句**"存储记忆"**,把本次目标/结果/教训沉淀进记忆库——下次同类任务会自动被预注入。

## 六、边界(不要期待)

- 阶段子会话互相隔离是**特性**(防上下文互染),跨阶段信息必须落文件。
- 单阶段 prompt 超时 25 分钟;判官连续两轮判定打转会强制收敛,不会无限烧。
- 编排器只保证"产物存在且判官通过",**不对业务正确性背书**——终审仍然是人。
