# 用户指令列表 — SimpleAIBrain 记忆系统

> 对 agent(任何已接入记忆系统的工作区)说这些口令即可触发对应操作。口令的**执行定义**在本仓库 `AGENTS.md` 的「记忆操作口令」节;本文是用户侧权威清单。
> 最后更新:2026-10-24(0.0.16.21)

## 记忆之门(hub)——连接与启动

**记忆系统的门是 hub(SimpleMcpServer)**:所有 `memory.*` 调用都走 `http://127.0.0.1:45678/rpc`(token 作 `_brainToken` 参数)。hub 不在,一切记忆操作不可用——报 `ECONNREFUSED`/`fetch failed` 就是门没开,不是没记忆。

| 事项 | 说明 |
|---|---|
| 检查是否在线 | `node scripts/enroll.mjs <目标工作区>`(SimpleAIBrain 仓库根执行;登记/查询时自动做门检查并打印 ONLINE/OFFLINE);或直接 POST `/rpc` 调 `memory.whoami` |
| 未启动怎么办 | **由用户在可见 cmd 窗口启动 hub**(SimpleMcpServer),启动后核对进程 banner 时间戳——这是运维纪律,防误连旧进程;agent 只报告与指引,不私自后台拉起 |
| 新工作区接入 | 运行 `登记记忆`(enroll.mjs):铸造 token 写 `.brain.json`(自动加入 .gitignore)+ 注册进 hub + 在该工作区 AGENTS.md 写入门牌(门地址/口令表/纪律)。之后先"获取记忆"验证一次 |
| agent 视角 | 新工作区的 agent 入手顺序:读本工作区 `AGENTS.md` 的记忆节(含门地址)→ 取 `.brain.json` token → `memory.whoami` 验证 → 正常干活;门没开时报告用户,等待可见窗口启动 |

## 口令

| 口令 | 作用 | agent 实际做什么 | 需要身份? |
|---|---|---|---|
| **存储记忆** | 强制保存当前会话的关键结论 | 读 `.brain.json` 取 token → `memory.submit_session`(digest,400-1200 字,带出处,不含密钥) | 需要(token 作 `_brainToken` 参数) |
| **获取记忆** | 读取一次工作区已有记忆 | token 作 `_brainToken` 参数 → `memory.context`(查询词=当前任务主题)→ 作为已知前提继续任务 | 需要(访客只能看 studio 作用域,通常为空) |
| **查找记忆 <关键词>** | 深挖单条记忆 | `memory.search` 逐条列出:标题、正文、id、来源 | 同上 |
| **记忆体检** | 汇报记忆库健康状况 | `memory.whoami`(身份)+ `memory.stats`(分层计数、近 7 天检索、上次巩固 run、needs_review 数)→ 一段话汇报 | 需要(stats 不对访客开放) |
| **生成用户身份** | 确保存在 member(s1/local)级用户凭证 | 运行 `node scripts/member-identity.mjs`(幂等:已有则打印位置;缺失则铸造并写入 `<hub>/data/member-credential.json`)→ 提示用户妥善保管 | 不需要 |
| **开自主任务 "目标" [阶段数 纠偏数]** | 用一条命令启动自主任务(编排器拆步+判官验收) | 运行 `node <SimpleAIBrain>/scripts/pipeline-start.mjs "<目标>" [stages] [budget]`(分离进程,日志在 `<工作区>/_pipeline/run-*.log`,完成弹窗);目标必须带引号;agent 汇报后即返回,不等待 | 不需要(工作区未登记则无记忆预注入,功能仍可用) |
| **自主任务状态** | 查看运行中的自主任务进度 | 读 `<工作区>/_pipeline/state.json` 阶段状态 + 日志尾 + 判官留痕尾,一段话汇报 | 不需要 |
| **停自主任务** | 结束运行中的自主任务 | 读 `_pipeline/run.pid` → `taskkill /F /T /PID`;确认后汇报 | 不需要 |
| **登记记忆** | 给当前工作区接入记忆系统 | 运行 `node scripts/enroll.mjs <目标工作区>`(在 SimpleAIBrain 仓库根执行;部署约定见下方「记忆之门」)(幂等:已登记则打印现状;未登记则铸造 token 写 `.brain.json` 并注册进 hub;默认 agent 标签=目录名) | 不需要(脚本自动铸造) |

### 登记路径(两种,均需先完成一次「记忆之门」检查)

1. **主会话代登记**:让 SimpleAIBrain 主 agent 执行 enroll——最稳,零歧义。
2. **新工作区自登记**:让新工作区 agent 先读 SimpleAIBrain 仓库 `docs/用户指令.md` 的「记忆之门」节,再执行 enroll。登记成功后,门牌自动写入该工作区 AGENTS.md,此后不再依赖外部文档。

> ⚠️ **严禁借用其他工作区的 token 存记忆**(2026-10-22 SimpleMcpServer 事故:agent 冒用 simpleaibrain 身份存了 4 条,已归档清理)。token 与工作区一一对应,拿不准就先问用户。

## 注意事项

1. **0 命中 ≠ 没记忆**:访客只见 studio 作用域。跨工作区查询先"登记记忆",再"获取记忆"。
2. **token 是密码**:`.brain.json` 不入 git、不外发;响应里出现 `note` 提示时按提示修正身份。
3. **重复"存储记忆"正常**:每次都是独立快照,巩固层会按主题归并,不会爆炸。
4. **删除不走口令**:遗忘/修订走 `memory.edit`(成员身份)+ needs_review 人工确认,防止 agent 一句话毁证据。

## 内置自动化(L0 自动摘要默认开启:agent 忘记提交摘要的会话在空闲后由系统自动摘要入库,权重上限 0.6,来源标 watcher:auto;每会话至多一次,人工提交的摘要永远优先;如需关闭,hub 配置 `aiBrain.ingest.autoDigest: false` 后重启)(无需口令)

- **会话开始读记忆**:AGENTS.md 约定,agent 自觉执行。
- **L0 原始转录**:DSH watcher 每 10 分钟对账空闲会话,自动入 L0(只作巩固原料,不可检索)。
- **每日巩固**:定时把 spool digest 升为 L1、归并 L2、蒸馏 L3;也可让 agent 转告用户手动 `POST /brain/consolidate`。
- **读侧钩子(0.0.15.2+,DSH 已挂载)**:登记工作区每次发言自动以原话为检索词注入相关记忆(结构化 additionalContext);新会话先注入全量底座。
- **注入节流三道闸(0.0.15.4)**:同内容永不重注;内容变化需间隔 ≥10 分钟;琐碎发言(<4 字符)跳过;钩子预算 2000。
- **常驻提示 + 防编造规则(0.0.15.5/0.0.16.0)**:全量横幅附「先查证再答,禁止编造」;AGENTS.md 增补未知指代/无出处常量/新鲜度错位三条行为规则。
- **记忆目录与领航灯(0.0.16.0)**:`memory.context` 新增 `tocOnly: true` 返回纯标题目录(不加新工具);钩子被节流但距上次全量 >30 分钟时注入 ~350 字符标题目录,让库的存在始终可见。
