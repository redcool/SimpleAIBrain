# 用户指令列表 — SimpleAIBrain 记忆系统

> 对 agent(任何已接入记忆系统的工作区)说这些口令即可触发对应操作。口令的**执行定义**在本仓库 `AGENTS.md` 的「记忆操作口令」节;本文是用户侧权威清单。
> 最后更新:2026-10-20(0.0.16.0)

## 口令

| 口令 | 作用 | agent 实际做什么 | 需要身份? |
|---|---|---|---|
| **存储记忆** | 强制保存当前会话的关键结论 | 读 `.brain.json` 取 token → `memory.submit_session`(digest,400-1200 字,带出处,不含密钥) | 需要(token 作 `_brainToken` 参数) |
| **获取记忆** | 读取一次工作区已有记忆 | token 作 `_brainToken` 参数 → `memory.context`(查询词=当前任务主题)→ 作为已知前提继续任务 | 需要(访客只能看 studio 作用域,通常为空) |
| **查找记忆 <关键词>** | 深挖单条记忆 | `memory.search` 逐条列出:标题、正文、id、来源 | 同上 |
| **记忆体检** | 汇报记忆库健康状况 | `memory.whoami`(身份)+ `memory.stats`(分层计数、近 7 天检索、上次巩固 run、needs_review 数)→ 一段话汇报 | 需要(stats 不对访客开放) |
| **登记记忆** | 给当前工作区接入记忆系统 | 运行 `node H:/ai_works/SimpleAIBrain/scripts/enroll.mjs`(幂等:已登记则打印现状;未登记则铸造 token 写 `.brain.json` 并注册进 hub;默认 agent 标签=目录名) | 不需要(脚本自动铸造) |

## 注意事项

1. **0 命中 ≠ 没记忆**:访客只见 studio 作用域。跨工作区查询先"登记记忆",再"获取记忆"。
2. **token 是密码**:`.brain.json` 不入 git、不外发;响应里出现 `note` 提示时按提示修正身份。
3. **重复"存储记忆"正常**:每次都是独立快照,巩固层会按主题归并,不会爆炸。
4. **删除不走口令**:遗忘/修订走 `memory.edit`(成员身份)+ needs_review 人工确认,防止 agent 一句话毁证据。

## 内置自动化(L0 自动摘要默认开启:agent 忘记提交摘要的会话在空闲后由系统自动摘要入库,权重上限 0.6,来源标 watcher:auto;每会话至多一次,人工提交的摘要永远优先;如需关闭,hub 配置 `aiBrain.ingest.autoDigest: false` 后重启)(无需口令)

- **会话开始读记忆**:AGENTS.md 约定,agent 自觉执行。
- **L0 原始转录**:DSH watcher 每 10 分钟对账空闲会话,自动入 L0(只作巩固原料,不可检索)。
- **每日巩固**:定时把 spool digest 升为 L1、归并 L2、蒸馏 L3;也可让 agent 转告用户手动 `POST /brain/consolidate`。
- **读侧钩子(0.0.15.2+,DSH 已挂载)**:登记工作区每次发言自动以原话为检索词注入相关记忆(结构化 additionalContext);新会话先注入全量底座。
- **注入节流三道闸(0.0.15.4)**:同内容永不重注;内容变化需间隔 ≥10 分钟;琐碎发言(<4 字符)跳过;钩子预算 2000。
- **常驻提示 + 防编造规则(0.0.15.5/0.0.16.0)**:全量横幅附「先查证再答,禁止编造」;AGENTS.md 增补未知指代/无出处常量/新鲜度错位三条行为规则。
- **记忆目录与领航灯(0.0.16.0)**:`memory.context` 新增 `tocOnly: true` 返回纯标题目录(不加新工具);钩子被节流但距上次全量 >30 分钟时注入 ~350 字符标题目录,让库的存在始终可见。

## 如何新增口令

1. 在 `AGENTS.md`「记忆操作口令」节写执行步骤(短句、见词即行、不反问)。
2. 在本表加一行,更新"最后更新"与版本号。
3. 提交信息按纪律:`x.y.z.w docs: ...`。
